## 6. Combat (Components.Characters/CharacterStats.cs, Entities.Combat/*MaxHitFormula.cs, TargetCharacterStats.cs)
  accuracy/evasion = floor((weighted level + 9)(stat + 64)) x (1 + %) [+ flat], then for the player only x (1 - 0.05 x clamp(area darkness, 0, 20)), truncated, min 1 (PlayerComponent.cs 243-246)
  hit chance = 1 - E/(2A) if A >= E else A/(2E), + flat, clamp 0..1  (same as Melvor 1)
  melee/ranged max hit = floor(22 + L + (L + 17)*S/64), algebraically equal to Melvor 1's floor(10*(1.3 + e/10 + S/80 + e*S/640)) with e = L + 9;
    over L 1-120, S 0-299 (36 000 pairs) they differ in 89: Melvor 1's float form floors 1 too low in 89 cases (e.g. L1 S32 -> 31 vs exact 32), Melvor 2's form is exact in all but 0
  magic max hit = floor(spellMaxHit x (1 + damageBonus) x (1 + (Magic + 1)/200)); HP = 10 x Hitpoints level; attack interval >= 250 ms
  resistance = clamp(clamp((protection/(power + protection) + flat) x (1 + %), 0, 0.70) x (1 + triangle), 0, 1) -> capped at 70 % before the combat triangle
    protection 100 vs power 100: base resistance 50 %
    protection 300 vs power 100: base resistance 70 %
    protection 1000 vs power 100: base resistance 70 %
    protection 100 vs power 300: base resistance 25 %
  combat level = max(1, floor(sum ratio x level)) per style (CombatStyle.cs ComputeCombatLevel): melee 0.325 Atk + 0.325 Str + 0.25 Def; ranged/magic 0.4875 x level + 0.25 Def; Hitpoints is not included (Melvor 1 added 0.25 x HP)
  enemies: 192; HP levels 1-2800

## 8. Offline, catch-up, sleep (Main.cs, Core.SleepDetection/SleepDetector.cs, Entities.OfflineProgress/OfflineProgressComponent.cs)
  load: if the save timestamp is >= 10 s old, run offline for the difference
  sleep detector: every 5 s compare wall clock with accumulated physics time; drift >= 10 s fires Wake
  drift <= 60 s -> Catchup mode; > 60 s -> Offline mode (snapshot + summary modal); both run the same PropagateTick() in a background Task, one tick per TickInterval of missing time
  max offline time = max(base, base + FlatOfflineTime), base 86 400 000 ms (24 h): modifiers can only raise it (OfflineProgressStats.cs 59-64)
  the IsOffline flag (Game.OnOfflineProgressStart) is set only on the sleep-wake path over 60 s (Main.cs 414, 426), not for load-time replays
  24 h = 5,184,000 ticks at 60 Hz (Melvor 1: 1 728 000 at 20 Hz)
  saves: 5 save files, autosave every 10 s (Constants.MaxSaveFiles, AutoSaveInterval)
