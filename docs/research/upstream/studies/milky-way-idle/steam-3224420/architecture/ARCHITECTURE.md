# Architecture
## Steam client (VERIFIED, local files)
`milkywayidle.exe` is Electron 32.0.2 (`version`), packaged with `@electron/packager` for Steamworks (`package.json` build scripts write straight into a `steamworks_sdk_160/.../ContentBuilder/content` tree). `resources/app/` is plain, unminified JavaScript (≈12 MB with node_modules): `main.js` (1 346 lines) opens a BrowserWindow on `https://www.milkywayidle.com` (or the China mirror `milkywayidlecn.com`, selectable in a menu), initialises Steam through `steamworks.js` with app build id 3224420 (`config.js`; 3224740 is the Steam app id and the test/local build id), keeps up to 10 isolated cache profiles (`cache-manager.js`, "Multicache" — one per concurrently open character window), logs events, and ships a full **userscript manager** (`ext-runtime/`, `script-manager/`: Tampermonkey-style `GM_*` API, `@require`, resources, per-script storage) — i.e. the developer officially supports client mods. **No game logic or data is in the install.**
## Web client (VERIFIED, public static files)
React app (Create-React-App chunks `main.8add56c3.chunk.js` 1.96 MB + vendor `2.2cfd5f74.chunk.js` 1.23 MB). It is a thin view over a **server-authoritative** game: one WebSocket (`wss://api.milkywayidle.com/...`), and after login the server pushes `init_client_data` (all static game tables: `itemDetailMap`, `actionDetailMap`, `combatMonsterDetailMap`, `abilityDetailMap`, `levelExperienceTable`, `enhancementLevelSuccessRateTable`, `houseRoomDetailMap`, shop/market/guild/labyrinth maps… — the initialiser lists 30+ maps) which the client caches compressed in localStorage. The client contains the **display-side copies** of most formulas (buff stacking, level-efficiency, enhancing success/speed, action time, monster tier scaling, combat-stat derivations, combat level, market tax) plus the in-game guide that documents the server formulas in prose. Combat resolution, drops and RNG run on the server; the client only animates results.
## Data used here
`init_client_data` was **not** captured (it requires logging in; out of scope). The 21 data maps in `evidence/data_maps/` are the copies the community combat simulator ships; every action/monster hrid in the client bundle (760/760, 95/95) and 957/958 item hrids match them (the one extra is `foolosophers_stone`), so their key sets are current with the 2026-09-28 client (coverage checks keys, not values; the values stay STRONG INFERENCE). Market prices come from `/game_data/marketplace.json`, which the developer announced in patch notes as a public hourly API (top ask/bid, average, volume per item and enhancement level).
## Implications
Everything that matters for balance is server-side and can change without a client update; the reliable evidence tiers are (1) client code, (2) developer-written guide text in the client, (3) the community simulator, which is validated by players against live combat logs but is not the server code.
