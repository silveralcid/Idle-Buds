# Super Auto Pets — Content Architecture (VERIFIED)
- **Definitions are code**: `MinionConstants` has one `Create…()` per pack/variant (Pack1Turtle, Pack2Puppy(+Custom,+Relics), Pack3Star(+Custom,+Beta,+Tokens), Pack4Golden, Pack5Unicorn, Pack6Danger, Pack7Color, Pack8PlusMini1–4, Pack9000Test, Relics Draft/Hard/Standard, Rework*, Draft, Misc, BullyMinions); each pet is built with a fluent `MinionTemplate` (`SetStats`, `SetTier(value,max)`, `AddAbility`, `AddPack`/`AddPackOwnership`, `SetArchetype*`, `SetRoles`, `SetToken`, `SetPremium`, `SetReleaseVersion`, `SetCountdown`, `SetTribeElements`, `AddStackRule`…). Same for `SpellConstants` (foods, 253 enum entries), `PerkConstants`, `AbilityConstants` (numeric constants like ChiliAttack, MelonArmor, FortuneCookieChance).
- **Abilities are compositions**: `Ability` = trigger object + targeting object + condition(s) + effect(s) + parameters + catalogue; ~270 primitive classes cover 850 pets. Ability text is generated from the composition (`CreateAbout`, `Ability.<Pet>Ability.<level>.About` strings), guaranteeing text/behaviour consistency across 13 locales.
- **Enums are the content IDs** (`MinionEnum` 850, `SpellEnum` 253, `TriggerEnum` 234, `Archetype` 30, `Pack` 35, `Perk`), append-only with test/unreleased entries kept.
- **Art**: 411 sprites in one Addressables group (UnityPy inventory) + per-pet "Poses" ScriptableObjects (animation poses, shadow scale); emoji-style art; audio 6 clips in the group (+ `sharedassets1.resource`).
- **Localization**: Unity Localization tables, 13 locales (en, es, fr, de, it, pt-BR, pl, ru, tr, ja, ko, zh-Hans, zh-Hant), 4 534 generated + 874 general keys.
- **Versioning**: `SetReleaseVersion`, `SetIncludeVersionChange/SetIgnoreVersionChange`, "Changes" TextAsset, `VersionResponse` DTO — content is versioned per pet for balance history and weekly rotation compatibility.
Lesson: for a game whose content is *behaviour* (not numbers), a typed in-code DSL with generated text beats JSON — the compiler checks every ability, and localisation follows automatically.
