# Palworld — Technical Architecture
Evidence: pak survey (`evidence/pak_filelist.txt`, `tools/ue-pak-export/pak_index.py`), exported config (`evidence/config/`), class model recovered from the reflection mappings (`evidence/classmodel/palworld_classes.md`: 11 964 structs/classes, 2 131 enums, 3 041 `Pal*` types), exported DataTables/DataAssets (`evidence/datatables/`, `evidence/assets/`). Tier VERIFIED unless marked.

## Engine and build
- **Unreal Engine 5.1** (`++UE5+Release-5.1` in `Palworld-Win64-Shipping.exe`, 161 MB), project `Pal`, **ProjectVersion 1.0.5.102999** (`Pal/Config/DefaultGame.ini`) — the 1.0 release line (July 2026+). Plugins shipped: Wwise (audio), DLSS/Streamline, Discord Partner SDK; manifests also list dev plugins `BPDefaultDumper` and `BlueprintCLI` (STRONG INFERENCE: internal tooling left in the build).
- Content container: one legacy **pak v11** `Pal-Windows.pak` (39.3 GB, 185 141 entries, mount `../../../`), **Oodle**-compressed (133 908 compressed / 51 233 stored), **not encrypted** (index and entries), no IoStore. `CrashReportClient.pak` beside it.
- Assets use UE5 unversioned property serialization → a `.usmap` reflection dump is mandatory for reading; the Sept-2026 community mappings (`evidence/mappings/`) match this build, the 0.6.x ones do not (struct layouts changed).
- Game logic lives in C++ (`/Script/Pal` module) and Blueprints (`Pal/Content/Pal/Blueprint/**`, e.g. 124 weapon BPs, 109 waza action BPs, ~200 build-object BPs). Only property names/types are recoverable from the client (no C++ source), so formulas are tiered STRONG INFERENCE/HYPOTHESIS unless they are literally tabulated.

## Content model (data-driven)
- **DataTables** (503 exported, 197 731 rows) under `Pal/Content/Pal/DataTable/*`: characters (`DT_PalMonsterParameter_Common` 753 rows of `PalCharacterParameterDatabaseRow`, `DT_PalHumanParameter`, `DT_PalBPClass`, `DT_PalDropItem` 1 029, `DT_PalCombiUnique` 258), skills (`DT_WazaDataTable` 385 active skills, `DT_WazaMasterLevel` 5 772 learn-by-level rows, `DT_WazaMasterTamago` 7 111 egg/inherit rows, `DT_PassiveSkill_Main` 1 905 passive rows, `DT_PartnerSkill` 50), items (`DT_ItemDataTable` 2 466, `DT_ItemRecipeDataTable` 1 414, `DT_ItemLotteryDataTable` 8 782, shops), technology (`DT_TechnologyRecipeUnlock` 588), progression (`DT_PalExpTable` 100 levels, `DT_PalCaptureBonusExpTable` 4 999, `DT_FriendshipRankTable`, `DT_BaseCampLevelData` 35, `DT_CharacterUpgradeMasterDataTable` 20 condenser ranks, `DT_PlayerStatusRankMasterDataTable` 279 effigy/relic ranks), world (`DT_PalWildSpawner` 1 691, `DT_PalSpawnerPlacement` 8 253, dungeons, incidents, fishing, arena, world-map areas, 11 778-row foliage placement tables), options (`DT_OptionWorldPresetTable` difficulty presets, `DT_OptionWorldModePresetTable`), and 27 English text tables under `L10N/en` (`DT_PalNameText_Common`, `DT_SkillNameText_Common` 1 158, `DT_ItemNameText_Common` 1 998, `DT_UI_Common_Text_Common` 3 188…).
- `_Common` tables are the real data; `DT_X` wrappers are `CompositeDataTable`s layering them (localization/platform overrides).
- **DataAssets**: `DA_StaticItemDataAsset` (2 455 typed item objects: 515 armor, 400 weapons incl. 12 sphere items (10 real tiers + debug + Radar), 286 consumables), `DA_BreedingItemEffectData`, `DA_PalBuildObjectCapabilityData`, skins, notes.
- Config: `DefaultPalWorldSettings.ini` (the public server-settings surface), `DefaultGame.ini`, `DefaultEngine.ini`, `DefaultGameplayTags.ini`.

## Runtime structure (from class names)
`PalGameMode`/`PalGameState` → `PalPlayerCharacter`, `PalMonsterCharacter` with `PalIndividualCharacterParameter` (level, HP, SP, hunger, sanity, status points, talents/IVs, passive skills, friendship, condenser rank, arena points — 48 multicast delegates on the parameter object) and `PalStaticCharacterParameterComponent` (species row). Combat: `PalDamageInfo` (base power, attacker level, element, weapon type, sneak-attack rate, special-attack-rate infos, PvP rates, explosion/partner-skill flags) → `PalDamageReactionComponent`, `PalDamageResult`. Capture: `PalCaptureJudgeObject` + `PalCaptureReactionComponent`, sphere BPs (`BP_PalSphere*` with `CaptureSphereType : EPalCaptureSphereLevelType`), `PalCaptureBonusExpTableSetting`. Breeding: `PalBreedingUtility`, `PalCombiMonsterParameter`, `PalBreedingItemEffectData`. Base: `PalBaseCamp*`, work suitability enums (13 jobs), `PalMapObject*` build objects with capability data. Networking: dedicated-server/co-op replication (`OverrideNetworkOwner`, replicate arrays); world settings control all rates.
