## 3. Mastery (skill.js getBaseMasteryXPToAddForAction, getMasteryXPToAddToPool, getBaseMasteryPoolCap, masteryTokenChance)
  mastery XP per action = ((unlocked * totalCurrentMastery / trueMax) + masteryLevel * (trueTotal/10)) * (interval_s) / 2
  pool gets xp/4 of every mastery XP gained (xp/2 once the skill is 99); pool cap = actions * 500 000; token chance = unlockedActions/185 % per action
  interval_s is the skill's masteryModifiedInterval: the real action interval for gathering skills and Thieving, but fixed 1.7 s Smithing/Runecrafting/Herblore, 1.3 s Fletching, 1.65 s Crafting, 4.85 s Summoning, 0.85 x base Cooking, 0.6 x base Firemaking
  for interval-based gathering skills mastery per HOUR does not depend on the interval (XP per action scales with it)

## 4. Combat (character.js)
  accuracy/evasion = (effectiveLevel + 9) * (bonus + 64); magic evasion uses floor(0.3*Def + 0.7*Mag); melee/ranged max hit = floor(10*(1.3 + e/10 + str/80 + e*str/640)), e = level + 9
  hit chance = 50*acc/eva % if acc < eva else (1 - 0.5*eva/acc)*100 %; damage *= 1 - resistance/100 (Normal cap 95 %); min hit 1; attack interval >= 250 ms, floored to 50 ms ticks; HP = 10 * Hitpoints level
  combat triangle (Standard set): player damage x 0.85-1.10 and player damage reduction x 0.75-1.25 by style matchup (combatTriangle.js 23-80; Hardcore set harsher)
    level  1, bonus   0: accuracy     640  melee max hit (strength bonus = bonus)   23

    level 99, bonus 150: accuracy  23,112  melee max hit (strength bonus = bonus)  392
    level 99, bonus 250: accuracy  33,912  melee max hit (strength bonus = bonus)  574
    accuracy/evasion = 0.5: hit 25.0 %
    accuracy/evasion = 1: hit 50.0 %
    accuracy/evasion = 2: hit 75.0 %
    accuracy/evasion = 4: hit 87.5 %
  monsters: 172 (base game); combat levels 1-1300, median 120; attack types {'melee': 97, 'ranged': 33, 'magic': 39, 'random': 3}
  combat level = floor(0.25*(Def + HP + floor(1/2)) + max(0.325*(Atk+Str), 0.325*floor(1.5*Rng), 0.325*floor(1.5*Mag)))  (monsters.js, prayer fixed at 1)

## 6. Loop and offline (game.js, combatManager.js, package.json)
  TICK_INTERVAL 50 ms; setInterval(loop, 50); processTime runs floor(elapsed/50) ticks, capped at MAX_PROCESS_TICKS = 20*60*60*24 = 1 728 000
  a loop gap >= 60 s (MIN_OFFLINE_TIME) enters the offline loop: the same tick() is run in batches sized to ~95 % of a 50 ms frame (OFFLINE_GC_RATIO), up to 24 h (MAX_OFFLINE_TIME)
  offline replays the same tick() for whatever keeps running, up to 24 h (1 728 000 ticks), with unseeded Math.random;
  but enterOfflineLoop stops combat unless settings.enableOfflineCombat is on (default off, five confirmations; game.js 2107-2114, settings.js 282-289) and Golbin Raid never runs offline
  the NW.js wrapper launches Chromium with --disable-raf-throttling and --disable-background-timer-throttling so the 50 ms interval keeps running when minimised
  autosave every 10 s; cloud check every 10 s (PlayFab auto cloud save default 23 h); client rich-presence update every 10 s, wrapper pushes to Discord every 15 s
