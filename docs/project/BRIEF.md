# Idle Buds project brief

Status: approved design direction; repository foundation established; gameplay not implemented by this mission.

Idle Buds is an idle-first creature-collection MMO concept for players who enjoy progressing at their own pace, developing meaningful creatures and participating in a shared economy and community. The [Bible](../design/design-bible.md) owns the exact identity, current choices and open questions. This brief routes readers rather than duplicating that specification.

The current deliverable is a clean, recoverable repository, complete project knowledge, applicable engineering/game standards, and a verified web development foundation. Legacy architecture does not dictate the new implementation. No gameplay, live services, deployment or production assets are part of this migration.

Follow the [Constitution](CONSTITUTION.md) and [current scope exception](../design/AUTHORITY.md). Research and Incubator content remain separate from approved design. A final release specification and gameplay milestone authorization are still required; the BEAT BAES public-demo gate is not established as satisfied.

[Architecture](../architecture/OVERVIEW.md) owns code boundaries. [Development](../engineering/DEVELOPMENT.md) owns setup.
