# Art direction reference

The [Rounds 1–2 HTML collection](rounds-1-2.html) is the complete original Drive file, preserved byte-for-byte with embedded boards, resources and notices. It is a nonfunctional visual exploration reference, not application code or production art.

Open it locally in a browser to explore the boards. The approved selection and remaining questions belong to [presentation and content](../../design/bible/10-presentation.md). The migration does not approve every board or asset in the collection. Track commercial rights separately before any production reuse; preserve embedded font and asset notices.

This directory is outside the runtime source and public asset tree. Its files must not be copied into a game build merely because they exist in the repository.

One preserved board requests an external Google Fonts stylesheet, so its typography can differ offline. Embedded React/ReactDOM headers and font-license comments are retained. The bundled generated renderer and illustrations are reference-only; no production redistribution rights are inferred from their presence.
