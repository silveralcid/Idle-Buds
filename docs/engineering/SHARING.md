# Source and release sharing

Idle Buds is the source of truth for this project. Preserve authorship, source commit references, licenses and migration provenance. This repository is not an anonymous reusable-template distribution. The upstream source-independence exporter is intentionally excluded because it rejects the source links this migration explicitly requires.

Share only a reviewed commit or release artifact. Review tracked files and generated bundles for secrets, personal data and third-party restrictions. Preserve notices. Exclude research, historical references, private evidence and unapproved assets from production bundles. A clean scan is bounded evidence, not a guarantee about all history.

Release authorization follows [delivery](../agents/delivery.md). Game release preparation is documented separately when the web foundation is configured.
