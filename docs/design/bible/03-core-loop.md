# 3\. Core gameplay design

## The interconnected loop

Gather and craft → earn the ability to catch monsters → catch and develop a collection → assign monsters to production or combat → breed and trade valuable specimens → refine teams and production → reinvest rewards into progression. Players choose which parts to emphasize. PvP, markets and cooperation create reasons to develop a collection beyond personal accumulation.
