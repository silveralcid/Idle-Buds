# 9\. Design governance and references

**The Game Development Constitution governs all work.** BEAT BAES remains the sole active implementation project until its demo is officially public and playable. Idle Buds is restricted to research, planning and design; no game code, functional prototypes, repository work, production infrastructure, implementation agents or production asset commissions. Approval of this Bible does not lift the gate.

**All new ideas enter the Idea Incubator before qualification.** Promote only with explicit owner approval. Design promotion does not approve release scope. The eventual Current Release Specification will separately establish must-ship scope, objective acceptance criteria and exclusions. Do not create it until sufficient design is established.
