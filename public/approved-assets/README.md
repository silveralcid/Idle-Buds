# Approved runtime assets

No game assets are approved or included in this foundation.

Only cleared, intentionally shipped assets belong here. Record creator/source,
rights, required notices and actual use before adding an asset. Historical art,
visual studies and reference-game assets belong outside the runtime. See the
[asset guidance](../../docs/game/assets-and-saves.md).

Vite's automatic public-directory copying is disabled. Import approved assets
explicitly from application source when needed so reference files and this
README are not copied into a production build by default.
