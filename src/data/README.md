# Runtime game data

The version-one catalog in `catalog.ts` is original MVP content. Stable IDs connect 15 species, four affinities, three zones and three progression tiers. Seven production tracks share gathering or recipe definitions. Four Tender combat tracks have separate XP. The rules use explicit catalog requirements for access, timers, capture supplies, gear and permanent upgrades.

The durations, prices, drops, rates, staff limits and balance values are provisional playtest inputs. Runtime data does not import research snapshots, proprietary content or legacy code.
